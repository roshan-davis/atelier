Export

Save finished photos as JPEG, HEIC, TIFF or PNG, with your edits, at the size and color space you need. Originals are never changed.

Open the Export dialog

Select photos and choose File › Export… (⇧⌘E), click Export in the toolbar, or right-click › Export…. In Loupe and Develop it exports the photo you're on (or the filmstrip selection).

  1. Quick settings fill in everything below in one click: Website (JPEG, 2048 px long edge, sRGB, sharpened for screen, no location), Full-Size JPEG, and Full-Size TIFF (16-bit, Adobe RGB, for print or further editing).
  2. Format: JPEG and HEIC (with Quality, 50 to 100), TIFF (16-bit) or PNG.
  3. Resize to fit: the long edge in pixels. Off keeps the full size.
  4. Color space: sRGB for web and social, Display P3, Adobe RGB (1998) or ProPhoto RGB. Sharpening: None or For screen.
  5. Metadata: All metadata, All except location (removes GPS), or None.
  6. Save to a folder. Atelier remembers your last choices.

While it runs

  • Exports run in the background, with progress and Cancel in the status bar. Keep working meanwhile.
  • Files keep their original names. An existing file is never replaced: a number is added instead. A virtual copy is named name-Copy1.jpg.
  • Keywords, title, caption and rating are written into the files (unless Metadata is None).
  • Photos whose drive is offline are listed under Show Problems; the rest still export.
