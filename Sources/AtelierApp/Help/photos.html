Virtual copies, stacks and removing

Make several versions of one photo without duplicating the file, see how versions stack, and take photos out of the catalog or move them to the Trash.

Virtual copies

A virtual copy is a second set of edits on the same file: a color and a black and white version, or two different crops.

  • Make one: right-click › Create Virtual Copy, or Photo › Create Virtual Copy (⌘'). Each selected photo gets one.
  • A copy starts with the photo's current edits, rating, label, keywords and collections (not its flag), then has its own of everything. Editing a copy never changes the original.
  • Copies sit right after the original in the grid with a ⧉ Copy 1 badge.
  • Remove one: right-click › Remove Virtual Copy…. Only the copy's settings go; the file is untouched.

Stacks

Edit In versions, AI results and virtual copies stack on their original: they sort right after it, join the same imports and collections, and the original shows the count (▤ 3).

Remove or delete photos

  1. Select photos and press Delete, or right-click › Remove Photo… (Remove 3 Photos… with several).
  2. The dialog says what will happen, with numbers: how many files, how many virtual copies go with them, how many are on a drive that isn't connected.
  3. Choose:
    Remove
    The default. Takes the photos out of the catalog, with their edits and metadata. The files stay where they are.
    Delete from Disk
    Also moves the files to the Trash.
    Cancel
    Nothing changes (or press Esc).

With RAW+JPEG pairs, the dialog has a checkbox per kind of file (for example “RAW (.NEF) 12 files” and “JPEG (.JPG) 12 files”); untick one to keep those files.

Nothing is erased silently. Files only go to the Trash. A network share like the NAS has no Trash, so Atelier asks before deleting from it immediately.

You'll hear the Dock's poof when something is removed from Atelier, and Finder's Trash sound when files go to the Trash. Turn this off in Settings › General › Feedback.
