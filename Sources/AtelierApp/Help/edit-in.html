Edit In other apps

Send a photo to Photoshop, Affinity Photo, Pixelmator Pro or any other editor, and get the result back in Atelier, stacked on the original.

How it works

  1. Select a photo and choose Photo › Edit In › Edit in Photoshop (the first app in the list is ⌥⌘E), or right-click › Edit In.
  2. Atelier saves a copy with your edits as name-Edit.tif next to the original (or in Pictures/Atelier/Edits if that folder is read-only) and opens it in the app.
  3. The copy appears in the grid right after the original, with a ◪ Edit badge. It joins the same imports and collections and gets the rating, label, title, caption and keywords.
  4. Save in the other app. Atelier sees the save and updates the preview.

Edit In on a photo that already is an edit opens that file as it is, so you can keep working on it.

Choose the apps

The menu lists the editors Atelier finds (Photoshop, Affinity Photo, Pixelmator Pro, Photomator, GIMP, Krita). Other Application… adds any app. In Atelier › Settings… › Edit In you can add, rename and remove apps, Find Installed Editors, and choose for each:

File
16-bit TIFF (best quality) or JPEG.
Color
ProPhoto RGB (the default, keeps every color), Adobe RGB, Display P3 or sRGB.
Include develop adjustments
On: the app gets your edited photo. Off: it gets the photo without Atelier's edits.
