Updates and What’s New

Atelier looks for new versions by itself, tells you what changed, and installs them when you quit, so an editing session is never cut short. A major version always asks first, and your catalog is backed up before any upgrade.

Check for a new version

  • Atelier › Check for Updates… looks now and always shows the answer: a new version with its notes, or “You’re up to date”.
  • Atelier also checks once a day in the background. It never opens a window over your work: when it finds a version later in a session, the menu item reads Atelier › Update Available: 1.3.0… and Settings › Updates says so. Choose it when you’re ready.
  • New versions come from Atelier’s releases on GitHub. Each one is signed, and Atelier refuses a download whose signature doesn’t match. Checking sends nothing about you or your photos.
  • Copies of Atelier run from Xcode never check; Settings › Updates says “Updates are off in builds run from Xcode”.

How updates install

Bug fixes (1.3.1)
Download in the background and install when you quit Atelier.
New features (1.4)
The same, and What’s New opens once the next time Atelier starts.
Major versions (2.0)
Always ask first, whatever the settings say, because they can upgrade the catalog so older versions can’t open it. The update window says so.
Install button
With Download and install updates automatically off, or on a copy that isn’t signed with a Developer ID, the update window’s Install Update downloads it and restarts Atelier; Remind Me Later and Skip This Version do what they say.

Include beta versions adds previews of the next release. Turn it off to go back to regular releases at the next one.

What’s New

  • Opens by itself once, the first time a new version starts. A fresh install doesn’t show it.
  • Help › What’s New in Atelier and Settings › Updates › What’s New in Atelier… show the notes for every version any time.

Your catalog across versions

  • Backed up before every upgrade. When a new version needs to change the catalog, Atelier first copies it to Backups › Before Upgrade inside the catalog (the last 3 are kept, apart from the backups made when Atelier quits). If that copy fails, the catalog isn’t changed and Atelier says why.
  • Going back to an older version. Minor versions only add to the catalog, so an older 1.x still opens it. After a major upgrade, an older version shows “This catalog was upgraded by a newer version of Atelier” and leaves it untouched: install the newer version again (Check for Updates… on that screen), or open the copy in Before Upgrade.

Opening Atelier the first time

A copy that isn’t notarized by Apple asks once before it opens: drag Atelier from the disk image to Applications and open it, then choose System Settings › Privacy & Security › Open Anyway and confirm. After that it opens normally and updates itself as above.
