General

Where the catalog is (Show in Finder) and how many photos it holds.

Show it at launch, Show Splash Folder (add your own images, ideally 1600 × 1000 px or larger; each launch shows the next), and Preview Splash Screen.
Feedback
Play a sound and a puff of smoke when deleting.
Previews
How much space thumbnails and previews use.

If the catalog cannot open

If Atelier cannot open its catalog, this screen replaces the splash. It names the location and reason. Try Again retries the same location after you resolve the problem, such as unavailable storage or access permissions. Show in Finder reveals the catalog, or its nearest available parent folder. Quit closes Atelier without making a catalog backup for the failed launch.

Atelier does not delete, replace or reset the catalog, or automatically restore a backup. An existing catalog folder missing its database is reported as a problem instead of opening an empty library. Keep the package and its Backups folder safe. Library commands and settings become available once the catalog opens. Help › Atelier Help remains available while you resolve the problem.

Appearance

Pick a theme from small previews. It changes every window at once.

System
Follows macOS, light or dark.
Light · Dark
macOS's own styles.
Graphite
Charcoal panels and a dark surround, like Lightroom.
Darkroom
Near black everywhere, so only the photo stands out.
Neutral Gray
A mid-gray surround, for judging color and brightness.

Import

The default for new imports (leave files where they are, or copy into the library folder), the library folder, and Show RAW+JPEG pairs as one photo.

Develop

Double-click or Z zooms to
50%, 100% (1:1), 200% or 400%.
When you move to another photo
Open it at Fit or Fill (the default); return to its last zoom; or keep the same zoom, as in Lightroom.
Panels
Solo mode (opening a panel closes the others) and the histogram's clipping warnings.

Export

The default export folder, and whether to show exported files in Finder. Format, size and color are chosen in the Export dialog.

Edit In

The external editors and what each one is sent. See Edit In.

AI

The ComfyUI server and Connect, the edit and upscale models, generation size, and the workflows folder. See AI tools.

Metadata

Automatically write changes into XMP sidecars, so other apps see your ratings, keywords and captions. See XMP sidecars.

Keyboard

Every single-key command (ratings, flags, labels, views, tools) with its key. Click a key and press a new one; a key moves from any command that had it. Delete removes a key, Esc cancels, Restore Defaults goes back to Lightroom's keys. Help › Keyboard Shortcuts (⌘/) lists them all.
