Library

Import photos

Bring a shoot into Atelier from a card, a drive or the NAS. Leave the files where they are, or copy them into your library folder.

Start an import

Any of these opens the Import dialog:

  • File › Import Photos… (⇧⌘I) or the Import button in the toolbar.
  • Drag folders or photos from Finder onto the Atelier window.
  • Right-click an import in the sidebar › Import More Photos Into This…

The Import dialog

  1. Photos: Choose Folders or Photos… or drag them in. Each source shows how many photos it has; ⊖ removes it, Add More… adds another.
  2. Import into: New import (named after the first folder; type another name if you like) or pick an existing import to add to.
  3. Files: Leave files where they are (on this Mac or the NAS; nothing is moved) or Copy into my library folder, in dated folders, each copy checked against the original.
  4. Apply During Import: a develop preset and keywords for every photo.
  5. Cull before importing: group similar shots and pick the keepers first. See Cull.
  6. The button says how many photos will be imported, and stays dimmed until there's at least one.

While it imports

The dialog closes, the new import is selected in the sidebar, and photos appear as they're added. The status bar shows progress and Cancel. When it's done it sums up what was imported, what was already in the catalog, and any files it couldn't read; Show Problems lists those with the reason.

Importing again is safe. Photos already in the catalog aren't added twice; they just join the import entry.

RAW+JPEG pairs

If your camera saves a RAW and a JPEG of each shot, Atelier shows them as one photo, the RAW, marked RAW+JPG. Ratings, flags, labels and keywords apply to both; editing and export use the RAW. Turn this off in Settings › Import › Show RAW+JPEG pairs as one photo.

Defaults

Atelier › Settings… › Import sets whether new imports leave or copy files, and where the library folder is. The dialog remembers your last choices.
