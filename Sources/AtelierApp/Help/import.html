Library

Import photos

Bring a shoot into Atelier from a card, a drive or the NAS. Leave the files where they are, or copy them into your library folder.

Start an import

Any of these opens the Import dialog:

  • File › Import Photos… (⇧⌘I) or the Import button in the toolbar.
  • Drag folders or photos from Finder onto the Atelier window.
  • Right-click an import in the sidebar › Import More Photos Into This…

The Import dialog

  1. Steps: where you are. Choose Photos › Import, or Choose Photos › Cull › Import with culling on. The dialog keeps the same size on every step.
  2. Sources: each folder or file you chose, with how many photos it has; ⊗ takes it out, Add… adds another. You can also drop folders or photos anywhere on the dialog.
  3. Photos: a thumbnail of every photo found (a RAW and its JPEG once).
  4. Import Into: a new import or an existing one. A new one is named after the first folder; the name is real text, so you can add to it or change it.
  5. File Handling: Leave files where they are (on this Mac or the NAS; nothing is moved) or Copy into my library folder, in dated folders, each copy checked against the original.
  6. Apply During Import: for every photo, a Develop preset, then a Tone Curve preset, then a Color Grading preset, and keywords. See Presets during import.
  7. Culling: Cull before importing groups similar shots so you pick the keepers first. See Cull.
  8. Import Preset (see Import Presets), what will happen, and the button, which says how many photos will be imported and stays dimmed until there's at least one. The panels on the right open and close like Develop's and stay as you leave them.

Presets during import

The three menus under Apply During Import are applied to every new photo in order: Develop settings, then Tone Curve preset, then Color Grading preset. The Tone Curve and Color Grading lists are the ones in those panels' Preset menus, so a panel preset changes only its panel and leaves the Develop preset's other settings alone. Where two overlap, the later one wins.

Each one is its own step in the photo's History: Import Preset: Portra 400, Import Tone Curve Preset: Matte, Import Color Grading Preset: Teal & Orange. Click an earlier step to see the photo without the later ones.

Import Presets

Save the dialog's settings to use again, as in Lightroom Classic. Click Import Preset at the bottom left:

  • Save Current Settings as New Preset…: name it. A preset keeps File Handling (and the library folder for copies), Apply During Import and Culling, but not the photos chosen or the import's name. Using a name that's already taken asks before replacing it.
  • Choose a preset by name to set all the panels at once. Change anything and the menu shows (edited). Update Preset saves the change.
  • Rename Preset… and Delete Preset change the chosen preset. None leaves the settings as they are and stops following a preset.
  • If a preset names a Develop, Tone Curve or Color Grading preset you've since deleted, that menu is set to None and the dialog says so.

While it imports

  1. The photos being imported, faint and grey until each one is in, then in full color with a check. The wall moves on by itself to keep the photos being copied in view. After culling it shows the photos you culled.
  2. How many are copied (or added, when files stay where they are), a progress bar and the file being copied.
  3. Copied, Speed and Time left.
  4. Run in Background and Cancel Import.

The dialog stays open and shows how far it has got: how many photos are copied (or added) in large figures, a progress bar, the file being copied, and how much is copied, the speed and the time left. Cancel Import (Esc) stops it; photos already copied stay in the catalog. Run in Background closes the dialog and keeps the progress, with Cancel, in the status bar. When every file is in, the dialog closes, the new import is selected in the sidebar and its thumbnails are made.

When it's done the status bar sums up what was imported, what was already in the catalog, and any files it couldn't read; Show Problems lists those with the reason.

With Cull before importing on, Continue to Cull moves the same dialog to the Cull step. Back returns to your settings as you left them.

Copied while you cull. As soon as the Cull step has listed the photos, Atelier starts copying them to your library drive, so by the time you click Import most of the copying is done and Import only moves each copy into its dated folder. The bottom of the Cull step shows how far it has got ("Copying to your library while you cull: 120 of 412"). Each copy is checked against the original when it's made; a photo that changes on the card afterwards is copied again. Back or Cancel throws these copies away. When files stay where they are, Atelier reads each one ahead instead, so Import has less to do.

Importing again is safe. Photos already in the catalog aren't added twice; they just join the import entry.

RAW+JPEG pairs

If your camera saves a RAW and a JPEG of each shot, Atelier shows them as one photo, the RAW, marked RAW+JPG. Ratings, flags, labels and keywords apply to both; editing and export use the RAW. Turn this off in Settings › Import › Show RAW+JPEG pairs as one photo.

Defaults

Atelier › Settings… › Import sets whether new imports leave or copy files, and where the library folder is. The dialog remembers your last choices.
