Set up

Connect a chat app

Ask a chat app about your library: “how many photos did I pick from the last import?”, “which photos from Iceland have five stars?”, “what Develop settings does this one use?”. Atelier speaks MCP, the standard way chat apps reach other apps, so any chat app that supports MCP servers can connect, with a free, local or hosted model.

What chat apps can do. With Look, chat apps read: search photos, look at their details, Develop settings and cull groups, and list the menu commands. With Organize they can also select photos in Atelier, rate, flag, label, add keywords, add notes and add to collections, each with Undo (see When an app changes photos). With Edit they can also edit in Develop: set or nudge sliders, run Auto, apply presets, sync and reset settings, crop and straighten, add masks and match a look, each a step in the photo's History with Undo (see When an app edits in Develop). They can also send several changes in one go, all or nothing with one Undo (see Several changes at once). In chat apps that show app views, such as Docent, found photos appear as a strip of cards (see Photos in the chat). Exporting from a chat comes in a later version; every menu command is already built so it can reach chat apps without extra work.

How it works

Every chat app below starts the same small helper, which is inside Atelier, with no arguments:

/Applications/Atelier.app/Contents/MacOS/atelier-mcp
  • Atelier must be open. The helper passes messages to the Atelier window; it never opens the catalog itself.
  • Atelier asks first. The first time an app connects, Atelier asks in its own window whether to allow it, and what it may do: Don't Allow, Look, Organize, Edit or Everything. Today every level can only read (see the note above); the higher ones are for organizing, editing and, with a second question in Atelier, exporting, as those arrive. Change it later in Atelier › Settings… › Agents.
  • Undo will work. When chat apps can make changes, each one will be one step in the photo's history, with a plain name, that ⌘Z undoes like your own edits.
  • Nothing is deleted. Chat apps can't remove photos or move files to the Trash; they tell you to use Photo › Remove Photo… yourself.

Settings › Agents

Atelier › Settings… › Agents is where you manage this (details in Settings › Agents):

Access
Allow chat apps to use Atelier (on; turning it off disconnects every app), Let agents see photo previews (off) and Include location in photo details (off).
Apps
Every app that has connected, with a green dot while it's connected and a menu of what it may do. Changing it reconnects the app; − forgets the app, so Atelier asks again. Apps started from Terminal are listed as Terminal.
Connect an App
The helper's path with Copy. Choose an app in Setup for and click Copy Setup; the line under it says where to paste.
Activity
What each app did, newest first. Select lines and click the copy button, or right-click for Copy and Copy All, to paste into a bug report.

Running Atelier from Xcode instead of /Applications? Build the helper once: Product › Scheme › atelier-mcp, then Product › Build (⌘B). Then use the path and setup that Connect an App shows.

OpenCode (free models)

OpenCode is a free chat app for Terminal with free hosted models, and it can use your Ollama models too.

  1. Add Atelier to ~/.config/opencode/opencode.json. The easy way: Settings › Agents › Connect an App, choose OpenCode in Setup for, click Copy Setup, paste it into Terminal and press Return. It runs a short script that adds Atelier and keeps what's already in the file. Or add it yourself, directly under "mcp": 
    {
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "atelier": {
      "type": "local",
      "command": ["/Applications/Atelier.app/Contents/MacOS/atelier-mcp"],
      "enabled": true
    }
  }
}
    Check it with opencode mcp list. "enabled": false turns it off without deleting it. (opencode mcp add didn't save anything when we tried it, so use the file.)
  2. Pick a model: type /connect to sign in to the OpenCode provider, then /models and choose one with no price (free models are free for a limited time and change often), or one of your Ollama models.
  3. Ask: “Use Atelier to list my collections.”

Cherry Studio

A desktop chat app that works with Ollama models and hosted ones.

  1. Open Cherry Studio's settings and choose MCP Server, then Add server.
  2. Name Atelier, Type STDIO, Command /Applications/Atelier.app/Contents/MacOS/atelier-mcp, Arguments left empty. Click Save.
  3. In a chat, turn on MCP in the chat box and select Atelier. Pick a model that can call tools, such as Gemma 4 or Qwen 3.6 from Ollama.

Ollama, with ollmcp (Terminal)

Ollama runs the model but doesn't connect to MCP servers itself, so a chat app sits in between. Any app on this page can use Ollama models; ollmcp (mcp-client-for-ollama) is the simplest one in Terminal. It needs Python 3.11 or later, with Ollama running.

uv tool install --upgrade ollmcp        # or: pip install --upgrade ollmcp
ollmcp mcp add atelier --scope user -- /Applications/Atelier.app/Contents/MacOS/atelier-mcp
ollmcp mcp list
ollmcp                                  # then pick qwen3.6 or gemma4 and chat

--scope user saves it in ~/.config/ollmcp/mcp.json for every folder. Without it, it's saved only for the current folder.

LM Studio

  1. In the right sidebar, open the Program tab and click Install › Edit mcp.json (LM Studio 0.3.17 or later).
  2. Inside "mcpServers": { … }, add: 
    "atelier": {
  "command": "/Applications/Atelier.app/Contents/MacOS/atelier-mcp",
  "args": []
}
  3. Save, load a model that supports tool use, and turn on the Atelier tools in the chat.

Open WebUI

Open WebUI connects to MCP servers over the network (Streamable HTTP, v0.6.31 and later), not to a helper it starts itself. Atelier's own network listener takes only paired phones (see From your iPhone), so put the helper behind mcpo, which serves it to Open WebUI as a tool server:

uvx mcpo --port 8000 --api-key "pick-a-secret" -- /Applications/Atelier.app/Contents/MacOS/atelier-mcp

Then add http://localhost:8000 in Open WebUI as an OpenAPI tool server, with the same key. Leave the Terminal window open while you chat.

Claude Desktop

  1. Choose Claude › Settings…, then Developer in the sidebar, and click Edit Config. It opens ~/Library/Application Support/Claude/claude_desktop_config.json.
  2. Add Atelier (if the file already has "mcpServers", add only the "atelier" part inside it): 
    {
  "mcpServers": {
    "atelier": {
      "command": "/Applications/Atelier.app/Contents/MacOS/atelier-mcp",
      "args": []
    }
  }
}
  3. Quit Claude completely (⌘Q) and open it again. If Atelier doesn't show up, the log is ~/Library/Logs/Claude/mcp-server-atelier.log.

Claude Code

claude mcp add --transport stdio --scope user atelier -- /Applications/Atelier.app/Contents/MacOS/atelier-mcp
claude mcp get atelier

Then type /mcp in Claude Code to see that Atelier is connected.

Codex

Add this to ~/.codex/config.toml (create the file if it isn't there), then start Codex again:

[mcp_servers.atelier]
command = "/Applications/Atelier.app/Contents/MacOS/atelier-mcp"
args = []

To turn it off without deleting it, add enabled = false. The Codex desktop app reads the same file.

From your iPhone

Docent on your iPhone can work with the Atelier open on your Mac: search and rate photos, look at them, edit and undo, with the same tools and the same approval cards as Docent on the Mac. The phone connects straight to Atelier over Tailscale, your private network between your own devices, so nothing is opened to Wi-Fi or the internet. Install Tailscale on the iPhone and sign in with the same account as the Mac. The Mac must be awake with Atelier open.

  1. Turn it on in Atelier › Settings… › Agents › Phone. It's off until you do. If your Mac's firewall asks whether Atelier may accept incoming connections, click Allow.
  2. Where the phone finds Atelier: your Mac's Tailscale name. Atelier listens only on the Tailscale address (never on Wi-Fi or Ethernet). Without Tailscale running it says Turn on Tailscale on this Mac to pair a phone, and starts again by itself when Tailscale connects.
  3. Pair a Phone… shows a QR code on the Mac's screen for 5 minutes. In Docent on the iPhone, choose Settings › Servers › Add › Scan Pairing Code and point the camera at it. The code works once; when it expires, click New Code.
  4. Each paired phone, with when it paired and was last used:
    • What it may do: Look, Organize, Edit or Everything. A new phone gets what Docent on the Mac may do (Edit if Docent hasn't connected here). Pairing the same phone again keeps its access and replaces its key.
    • This app asks for me: Atelier never asks anything on the Mac for a phone, because you may not be there. It's on for a newly paired phone. With it on, the phone's own Allow card is the only approval, for example for a change to more photos than Ask before one change touches more than allows. With it off, those changes fail on the phone straight away, saying where to turn this on.
    • Revoke stops the phone at once, even mid-conversation. The phone says Atelier no longer accepts it; pair it again to bring it back.

Each call from the phone shows in Activity, and edits in each photo's History, under the phone's name.

Which model

  • Claude and Codex are the most reliable at choosing the right command among many.
  • Local models (Gemma 4, Qwen 3.6 in Ollama) can call tools but miss more often. Atelier keeps their command lists short, and anything risky is confirmed in Atelier's window, not in the chat.
  • Free hosted models in OpenCode vary. Pick one marked for tool use.

Privacy

  • The helper talks to Atelier on your Mac only; Atelier makes no network calls for this.
  • With Ollama, nothing leaves your Mac. With a hosted model (Claude, Codex, OpenCode's free models), what Atelier answers goes to that provider as part of the chat. So photo previews and locations are off by default, with switches in Settings › Agents. Private photos are never shared.

If it doesn't work

“Atelier isn't running”
Open Atelier, then ask again.
The app isn't allowed
Settings › Agents › Apps lists every app that connected. Change Don't Allow to Look or higher. Check Activity for the error, and copy it if you need help.
The model never uses Atelier
Small free or local models often answer without calling tools. Ask directly (“use the Atelier tools to list my collections”), or pick a model that supports tool use.
The photo doesn't appear in the chat
Turn on Let agents see photo previews in Settings › Agents, then ask “show me the photo Atelier is looking at, here in the chat”. The chat app shows it only if it can show images (Docent can; Cherry Studio shows “Image blocked”). Asking to show photos in Atelier selects them in Atelier's own window instead. Connected chat apps pick up the switch without reconnecting.
Wrong path
If Atelier isn't in /Applications, copy the helper's path from Settings › Agents › Connect an App.
